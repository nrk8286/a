# SkillSwapCash.com Project

This repository contains the complete implementation of SkillSwapCash.com, a peer-to-peer skill marketplace.

## Project Structure

- **`skillswapcash/`** - Complete React 18 frontend application
- **`ai-market-plus-stripe/`** - Legacy Cloudflare Worker (for reference)

## Getting Started

Navigate to the `skillswapcash/` directory to run the main application:

```bash
cd skillswapcash
npm install
npm run dev
```

For detailed documentation, see [skillswapcash/README.md](./skillswapcash/README.md).

## Features

✅ Complete React 18 + Vite + Tailwind CSS frontend  
✅ 12 fully functional pages  
✅ JWT authentication system  
✅ Responsive mobile-first design  
✅ Stripe payment integration ready  
✅ Service marketplace with booking system  
✅ Real-time messaging interface  
✅ User profiles with portfolio and reviews  

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- React Router
- React Query
- Axios
- Zod
- Lucide React Icons
